## 솔루션 개요

인천 누림지도는 여러 기관의 장애인복지 프로그램 탐색과 신청, 기관별 모집·설문 관리를 하나의 웹 화면에서 지원합니다. 이용자는 자신에게 맞는 프로그램을 찾아 신청하고, 담당자는 프로그램과 접수 자료를 관리할 수 있습니다.

## 주요 기능 및 AI 활용

검색·분류, 프로그램 안내, 신청·동의·파일 제출, 모집 상태 관리, 기관별 담당자 권한, 설문과 Drive 저장 연계를 제공합니다.

AI는 코드 개발과 개선, 테스트 보조 및 이미지 제작에 활용했습니다. 사용자에게 AI 상담·추천 기능을 제공하는 서비스라는 의미는 아닙니다. 사용 도구와 역할은 [AI 활용 문서](AI_AND_SOURCES.md)에 구분했습니다.

## 최종 제출 시 기관에서 완성할 항목

- 기관 소개, 팀원 성명·소속·역할
- 실제 현장 문제와 기존 업무 방식에 대한 근거
- 적용 기간·대상·전후 변화 및 실제 성과 자료
- 이용자·담당자 피드백과 개선 사례, 남은 한계
- 외부 지원 주체와 실제 지원 범위
- 운영·확산 계획, 개인정보 보유·삭제 및 보안 점검 결과
- 필요한 경우 개인정보를 제거한 데모 영상

공개 소스의 존재만으로 현장 성과나 보안 점검 완료를 주장하지 않습니다. 제출 양식에는 위 GitHub 공개 링크를 넣고, 운영 키·비밀번호·인증 토큰 및 실제 신청 자료를 붙이지 마세요.
