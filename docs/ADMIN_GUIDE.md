# 관리자 가이드

## 구조

브라우저의 HTML/CSS/JavaScript 화면이 Supabase Auth·PostgreSQL·Storage·Edge Functions와 연결됩니다. Edge Functions는 권한을 확인하고 Google Apps Script를 통해 Drive의 파일·명단 및 설문 자료를 처리합니다. 정적 화면은 Netlify 등 정적 호스팅에서 제공합니다.

- 화면: 루트 HTML/JS/CSS 및 assets
- 신청 서버: backend/swift-processor.ts
- 설문 서버: backend/nurim-survey.ts, survey-core.mjs
- Google 연계: backend/google-apps-script.gs
- 신규 데이터베이스: backend/schema.sql → backend/storage-setup.sql → backend/retention.sql → backend/guardian-consent.sql
- 회귀 검증: tests
- 현재 설치 파일만 제공하며 파일명에 개별 버전 번호를 붙이지 않습니다.

## 담당자 운영

[설치 안내](SETUP.md)에 따라 총괄 관리자와 기관을 준비합니다. 총괄 관리자는 기관 및 담당자 권한을 관리하고, 기관 담당자는 소속 기관의 프로그램과 신청 업무를 처리합니다.

프로그램 등록 시 대상·일정·모집 방식·정원·동의 항목·신청 항목을 확인합니다. 필요한 경우 템플릿이나 홍보 이미지를 첨부하고, Google 연계 폴더와 설문을 설정합니다. 실제 공개 전에는 별도 시험 프로그램으로 신청·수정·취소·대기 순번·설문·Drive 저장을 확인하세요.

## 개발·유지보수

AI 보조로 화면과 백엔드를 반복 개선하고 신청·저장·설문 로직의 회귀 테스트를 구성했습니다. 코드 변경 후 npm test, npm run check:public, npm run build를 실행합니다. 서버 함수와 Apps Script는 각각 별도 배포가 필요합니다.

기관 인수인계 시 계정 소유권, 관리자 권한, Drive 폴더 권한, 배포 담당자 및 데이터 보유·삭제 절차를 확인합니다. 운영 로그에는 개인정보나 토큰을 남기지 않습니다. 서비스별 비용·할당량과 오류 로그를 해당 관리 화면에서 확인합니다.

이 공개판은 운영 신청 기록을 포함하지 않습니다. 실적·이용자 만족도·업무시간 절감 수치는 별도의 실제 기록으로 검증해야 합니다.

## 관리자 화면과 설문
관리자 버튼을 누르면 새 탭의 admin.html에서 중앙 로그인 화면을 엽니다. 설문 관리에서는 왼쪽에서 편집하고 오른쪽에서 실제 이용자 화면을 확인합니다. 옆 도구로 문항·페이지를 추가하고 문항을 끌거나 위·아래 버튼으로 이동합니다. 새 설문은 제목 다음에 바로 문항을 작성하고, 두 번째 페이지부터 제목·설명을 추가합니다. 안내문에서는 안내만 표시·동의/미동의·동의만 필수 확인을 선택합니다. 수정 후 저장하고 신청에 사용을 눌러 프로그램에 반영합니다.

문항은 별도 끌기 버튼 없이 제목 영역을 잡아 옮깁니다. 페이지에는 위·아래 버튼을 표시하지 않으며, 일반 문항에는 키보드용 이동 버튼을 유지합니다.

만 14세 미만 신청에서는 아동의 신청자 서명과 법정대리인의 추가 동의를 구분해 확인합니다. 보유기간 경과 자료의 데이터베이스 정리 기록을 확인하고, Google Drive·Storage 파일 정리는 기관 기준에 따라 별도로 처리합니다.
