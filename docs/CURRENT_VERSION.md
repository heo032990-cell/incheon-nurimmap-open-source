# 현재 공개 버전: 109.0.0

현재 기능을 모두 포함한 공개 소스입니다. 파일은 버전 번호가 아닌 기능 이름으로 구분하며, 별도의 구버전 파일이나 배포 ZIP을 포함하지 않습니다.

## 포함 기능
- 프로그램 검색·분류·신청 및 신청 내역 조회
- 기관별 관리자 권한과 새 탭에서 열리는 관리자 로그인 페이지
- 중앙 로그인 화면과 편집 영역 옆 문항 도구
- 왼쪽 설문 작성·오른쪽 실시간 이용자 미리보기
- 설문 제목 다음에 첫 문항 작성, 추가 페이지의 제목·설명 설정
- 문항 끌어 이동과 키보드용 위·아래 이동
- 안내만 표시 / 동의·미동의 / 동의만 필수 확인
- 최대 10개, 합계 10MB 신청서·증빙자료 첨부 및 개별 원본 저장
- 검색 안내·신청 단계 이동·문항 이름 연결 등 접근성 보조

## 현재 파일 구성
| 구분 | 파일 |
| --- | --- |
| 이용자·관리자 화면 | index.html, admin.html, admin-page.js |
| 설문 | survey-admin.mjs, survey-form.mjs, survey-core.mjs, survey.css |
| 신청 서버 | backend/swift-processor.ts |
| 설문 서버 | backend/nurim-survey.ts |
| Google 연계 | backend/google-apps-script.gs |
| 신규 설치 SQL | backend/schema.sql, backend/storage-setup.sql, backend/retention.sql, backend/guardian-consent.sql |
| 화면 스타일 | styles.css, ui-illustrated-header.css, ui-public-layout.css, ui-admin-layout.css, ui-responsive-layout.css |
| 실행·검증 | package.json, scripts/, tests/ |

각 스타일 파일은 서로 다른 화면 역할을 담당하며 모두 현재 구성에 필요합니다. 코드 내부의 API 주소·통신 규약·저장 형식에 포함된 숫자는 공개 버전 번호가 아니므로 호환성을 위해 유지합니다.

## 설치 및 확인
[설치 안내](SETUP.md)에 따라 본인의 계정과 연결 설정을 준비하세요. 신규 설치에는 위의 현재 서버·Apps Script·SQL 파일을 사용합니다. npm test, npm run check:public, npm run build로 검사합니다.

현재 운영 변경을 공개판의 독립 설정 구조에 맞게 반영했으며 공개 기능 버전은 109.0.0입니다. 운영 사이트와 비공개 작업 소스는 변경하지 않습니다.

문항은 별도 끌기 버튼 없이 제목 영역을 잡아 옮깁니다. 페이지에는 위·아래 버튼을 표시하지 않으며, 일반 문항에는 키보드용 이동 버튼을 유지합니다.

출력물에서는 페이지 제목을 전체 너비의 구분선과 페이지 번호로 표시하고 질문 번호는 연속으로 이어집니다. Google PDF에는 현재 backend/google-apps-script.gs를 기존 웹 앱의 새 버전으로 배포해야 적용됩니다. 이미 저장된 PDF는 자동 변경되지 않습니다.

## 현재 보호자 동의·보유기간 기능
만 14세 미만 신청에는 아동 서명과 보호자 이름·추가 서명·동의를 함께 기록합니다. 서버와 데이터베이스에서도 검증합니다. 개인정보 보유기간은 접수 당시 기준으로 보관하며 만료된 데이터베이스 기록을 정기적으로 정리합니다. Google Drive 자료와 Storage 파일은 별도의 정리 대상입니다. 남은 Storage 첨부가 있는 기록은 자동 삭제를 보류합니다.

## 프로그램 문의처·관리자 접근성 개선
신청 동의 안내에 해당 프로그램의 운영기관과 연락처를 표시하며, 연락처가 없으면 공통 대표전화를 사용합니다. 관리자 화면에 큰 글씨·색반전 버튼을 추가하고 상단 버튼 크기를 통일했습니다. 홍보 홈페이지 주소 입력란은 사용할 수 있으며, 링크 내용 자동입력 버튼만 숨깁니다. 이미지·PDF 홍보지 자동입력은 유지합니다.

## v109 적용 내용
홍보 홈페이지 주소를 다시 입력할 수 있습니다. 아직 사용하지 않는 링크 내용 자동입력 버튼만 숨기고, 자동입력 안내는 이미지·PDF 홍보지 기준으로 정리했습니다. 현재 서버·Google Apps Script·SQL 파일은 그대로 사용합니다.
