기관 Google Form 연결 안내

운영자가 먼저 서버와 중앙 Apps Script 연계를 설치한 뒤 진행합니다. 아래 코드는 기관 Form별 연결 절차입니다.

  1. 기관 Google 계정으로 Form을 만들고 응답 스프레드시트를 연결합니다.
  2. 관리자 화면에 Form 주소를 입력하고 프로그램을 저장합니다.
  3. 최초 연결 창에서 제공하는 연결 코드를 복사합니다.
  4. 해당 Form의 스크립트 편집기에 제공된 코드를 넣고 저장합니다. 기존 사용자 코드는 먼저 별도로 백업하세요.
  5. setupNurimConnection을 한 번 실행하고 해당 기관 계정으로 권한을 허용합니다. 이 Form별 연결 스크립트에는 별도 웹 앱 배포가 필요하지 않습니다.
  6. 가상 정보로 시험 제출한 뒤 사이트의 제출 확인 결과를 점검합니다. 같은 Form은 반복 연결하지 않습니다.

연결 코드·비밀 값·응답 자료는 공개 저장소에 올리지 마세요.
