# AI 활용 및 외부 자료

## AI 활용 범위

OpenAI Codex를 개발 보조 도구로 사용하여 화면과 서버 코드 작성·수정, 오류 분석, 문서 및 테스트 준비를 수행했습니다. 이미지 생성 도구를 통해 등대 아이콘과 인천을 모티브로 한 배경 이미지를 제작·수정했습니다. 이는 개발 과정의 AI 활용입니다. 현재 앱은 별도의 LLM API 키나 AI 챗봇 서버를 요구하지 않습니다.

AI 생성 배경은 인천의 분위기를 표현한 일러스트이며 정확한 행정경계·측량 지도나 공식 지도가 아닙니다. 아이콘·배경을 기관 공식 심볼이나 공식 인증으로 표시하지 마세요.

## 외부 자료·서비스

| 항목 | 용도 | 조건·출처 |
| --- | --- | --- |
| Supabase JavaScript 2.112.4 | 인증·데이터·스토리지 연결 | MIT, [소스와 라이선스](https://github.com/supabase/supabase-js) |
| Supabase | Auth, PostgreSQL, Storage, Edge Functions 호스팅 | 외부 서비스, [공식 문서](https://supabase.com/docs) 및 서비스 조건 |
| Google Apps Script / Drive / Forms | 명단·파일·설문 연계 | 외부 서비스, [공식 문서](https://developers.google.com/apps-script) 및 서비스 조건 |
| Netlify | 정적 웹 호스팅 | 외부 서비스, [공식 문서](https://docs.netlify.com/) 및 서비스 조건 |
| 기관 홈페이지 링크·프로그램 안내 | 정보 연결 | 해당 기관이 제공하는 원자료의 권리·이용 조건 적용 |

공개판 예제의 기관·프로그램은 설명용 가상 자료입니다. 운영 데이터베이스의 신청자·계정·설문 응답은 포함하지 않았습니다. 기존 화면 코드에 남아 있는 공개 기관 링크는 해당 기관의 공식 참여나 추천을 뜻하지 않습니다.

인천시 공식 심볼은 공개판에 포함하지 않았습니다. 별도로 사용하려면 권리자의 이용 조건을 확인하세요.

테스트에는 PGlite 0.3.14(Apache-2.0)를 사용합니다. 외부 계정 없이 임시 PostgreSQL에서 초기 구조와 권한을 검증하며, 운영 데이터베이스에 접속하지 않습니다.
