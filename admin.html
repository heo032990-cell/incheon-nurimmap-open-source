Google 신청서 연결 방법

새 Google Form마다 최초 한 번만 아래 순서로 연결합니다.

  1. 기관 Google 계정으로 Form 만들기Form의 응답 탭에서 응답 스프레드시트도 연결합니다.
  2. Form 주소 입력 후 프로그램 저장이 화면에 Google Form 주소를 입력하고 프로그램 저장을 누릅니다.
  3. 연결 코드 복사저장 직후 열리는 최초 1회 연결 창에서 연결 코드를 복사합니다.
  4. Form의 Apps Script에 붙여넣기Google Form의 더보기(⋮) → 스크립트 편집기에서 기존 코드를 지우고 붙여넣은 뒤 저장합니다.
  5. setupNurimConnection 1회 실행함수 목록에서 setupNurimConnection을 선택해 실행하고 기관 Google 계정으로 권한을 허용합니다. 배포 → 새 배포는 하지 않습니다.
  6. 테스트 제출 확인신청서를 실제 제출한 뒤 사이트의 신청서 제출 확인이 완료되는지 확인합니다.
기억하세요

같은 Form은 다시 연결하지 않습니다. Form 주소를 다른 Form으로 바꾼 경우에만 새로 연결합니다.

기관 Google Form 최초 1회 연결

아래 코드를 복사한 뒤 기관 Form의 Apps Script에 붙여넣고 setupNurimConnection을 한 번 실행하세요.

코드 복사 후 할 일Form 더보기(⋮) → 스크립트 편집기 → 기존 코드 삭제 → 붙여넣기 → 저장 → setupNurimConnection 선택 → 실행 → 권한 허용Apps Script의 배포 → 새 배포는 누르지 않습니다.

연결 코드 복사를 누른 뒤 복사 완료 안내를 확인하세요.
