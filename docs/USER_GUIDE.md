# 이용자 가이드

## 준비

최신 웹 브라우저와 인터넷 연결을 준비합니다. 일반 프로그램 조회에는 담당자 로그인이 필요하지 않습니다. 공개판 예제는 가상 자료이며 신청 정보를 수집하지 않습니다.

## 프로그램 찾기와 신청

1. 운영 서비스에서 검색어와 대상·활동 분류를 선택합니다.
2. 상세 안내에서 모집 기간, 일정, 비용, 대상, 정원과 문의처를 확인합니다.
3. 신청 가능한 프로그램의 신청 화면을 엽니다.
4. 기관이 요청한 항목을 입력하고 개인정보 안내와 동의 항목을 확인합니다. 필요한 경우 신청서 파일을 첨부합니다.
5. 제출 결과와 접수 상태를 확인합니다. 선착순·추첨 등 모집 방식에 따라 상태가 달라질 수 있습니다.
6. 설문이 연결된 경우 화면 안내에 따라 제출하고 확인 결과를 점검합니다.

## 신청 후

신청 조회 화면에서 본인 확인 정보를 입력해 내역을 확인합니다. 허용된 항목은 수정하거나 신청을 취소할 수 있습니다. 접수 완료가 모든 프로그램의 최종 참여 확정을 의미하지는 않으므로 기관 안내를 확인하세요.

화면 확대·키보드 이동 등 접근성 기능을 사용할 수 있습니다. 문제가 발생하면 해당 프로그램의 기관 문의처로 연락하세요. 공개 GitHub 이슈에는 이름, 생년월일, 전화번호, 신청서나 접속 키를 첨부하지 마세요.

## 신청서·증빙자료 첨부
파일 추가에서 PDF·한글·워드·사진·ZIP을 최대 10개, 합계 10MB까지 추가할 수 있습니다. 여러 번 선택해도 기존 파일 목록이 유지됩니다. 잘못 고른 파일은 해당 파일의 삭제 버튼으로 제거하세요. 직접 하나의 PDF나 ZIP으로 합칠 필요가 없습니다. 원본 파일은 각각 저장됩니다.
